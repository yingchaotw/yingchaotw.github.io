設計自己的 dialog menuconfig

設計自己的 lxdialog menuconfig：一個完整的範例 了解 lxdialog 與 menuconfig lxdialog 是一個用於在終端中建立對話框的工具，常被用於簡單的設定工具或腳本互動。 menuconfig 是一種基於文字的配置界面，常在嵌入式系統或 Linux kernel 配置中看到。 結合兩者，我們可以建立一個用 lxdialog 繪製介面，並採用 menuconfig 的配置風格的工具。 建立一個簡單的 menuconfig 範例 1. 準備工作: 安裝 lxdialog: sudo apt install lxdialog # Ubuntu/Debian 選擇一個腳本語言: 我們以 Bash 為例，因為它在 Linux 系統上廣泛使用。 2. 撰寫腳本: #!/bin/bash # 定義選項 options=( "選項一" "選項二" "選項三" ) # 使用 lxdialog 顯示菜單 dialog --title "我的配置工具" --menu "請選擇一個選項:" 0 0 $((${#options[@]} * 3)) "${options[@]}" 2>output.txt # 根據選擇執行不同動作 option=$(<output.txt) case $option in 1) echo "您選擇了選項一" # ... 執行相關操作 ;; 2) echo "您選擇了選項二" # ... 執行相關操作 ;; 3) echo "您選擇了選項三" # ... 執行相關操作 ;; *) echo "無效的選項" ;; esac ...
