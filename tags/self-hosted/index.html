使用 Docker 和 Docker Compose 部署 dnsmasq 和 Nginx

這篇筆記將指導您如何使用 Docker 和 Docker Compose，將 dnsmasq 作為 DNS 服務器和 nginx 作為 Web 伺服器進行部署。 1. 項目目錄結構 首先，我們需要設置一個專案目錄結構，便於管理所有配置文件和 Docker 配置。 docker-dns-proxy/ ├── docker-compose.yml # Docker Compose 配置文件 ├── nginx/ # Nginx 配置目錄 │ └── default.conf # Nginx 設定檔 └── dnsmasq/ # dnsmasq 配置目錄 └── dnsmasq.conf # dnsmasq 設定檔 2. docker-compose.yml 配置 docker-compose.yml 是用來定義和管理多個 Docker 容器的配置文件。在這個例子中，我們將設置兩個服務：dnsmasq 和 nginx。 範例配置 version: '3.8' services: dnsmasq: image: andyshinn/dnsmasq:2.78 container_name: dnsmasq ports: - "53:53/udp" # DNS 端口 - "53:53/tcp" # DNS 端口 volumes: - ./dnsmasq/dnsmasq.conf:/etc/dnsmasq.conf # 映射配置文件 restart: always # 容器異常退出後自動重啟 nginx: image: nginx:latest container_name: nginx ports: - "80:80" # HTTP 端口 - "443:443" # HTTPS 端口 volumes: - ./nginx/default.conf:/etc/nginx/conf.d/default.conf # 映射 Nginx 配置文件 depends_on: - dnsmasq # 確保 dnsmasq 容器先啟動 restart: always # 容器異常退出後自動重啟 說明： dnsmasq 服務使用了 andyshinn/dnsmasq Docker 映像，並將端口 53 映射到主機，處理 DNS 請求。 nginx 服務使用官方的 nginx Docker 映像，並映射了 80 和 443 端口來處理 HTTP 和 HTTPS 請求。 3. 配置 dnsmasq dnsmasq 用來提供 DNS 解析服務。在此，我們設置了基本的 DNS 配置。以下是 dnsmasq.conf 的範本： ...
