在 Hugo 部落格中嵌入 n8n Demo 組件

如果你在使用 Hugo 部落格系統，並且希望在文章中展示 n8n 的 workflow，這篇文章將教你如何快速將 n8n-demo 組件嵌入你的 Hugo 文章中，並且正確處理 workflow JSON 的格式。 什麼是 n8n-demo 組件？ n8n 是一個開源自動化工具，讓你可以在圖形介面中設計工作流程（workflow），並且連接各種不同的 API 或服務。而 n8n-demo 是一個可以將 n8n 工作流程嵌入到網頁中的 Web Component，讓你可以在文章或頁面中預覽這些流程。 步驟一：安裝與設置 Hugo 如果你還沒有設置 Hugo 部落格，你可以參考 Hugo 官方文檔 來進行安裝和初始化。一旦安裝完成，記得選擇一個適合的主題，這裡我們將使用 PaperMod 主題來進行展示。 步驟二：允許 Hugo 解析 HTML 元素 在 Hugo 中，默認情況下並不允許 Markdown 中使用 raw HTML 元素（像是 <script> 標籤）。為了能夠嵌入 n8n-demo 組件，我們需要讓 Hugo 允許這些 HTML 標籤。 修改 config.toml 打開你的 Hugo 配置文件 config.toml，加入以下設置： [markup] [markup.goldmark] [markup.goldmark.renderer] unsafe = true 這樣，Hugo 就能夠正確解析 Markdown 中的 <script> 和 <n8n-demo> 標籤。 ...
