ssh 金鑰管理與設定

關於 SSH 金鑰重新命名與 config 檔案修改 重新命名 SSH 金鑰檔案 完全可以將 ssh-keygen 生成的 id_ed25519 和 id_ed25519.pub 檔案重新命名為更有意義的名稱，例如 id_ed25519_pro 和 id_ed25519_pro.pub。這有助於你管理多個 SSH 金鑰時，更清楚地辨識每個金鑰的用途。 重新命名步驟： 關閉 SSH 連線： 在你開始重新命名檔案之前，請確保沒有任何 SSH 連線正在使用這些金鑰。 找到金鑰檔案： 這些檔案通常位於你主目錄下的 .ssh 目錄中。 使用檔案管理工具或終端機： 直接將檔案名稱改為你想要的。 修改 .ssh/config 檔案 修改 .ssh/config 檔案，可以讓你自定義 SSH 連線的行為。當你重新命名金鑰檔案後，就需要對應地修改 config 檔案，讓 SSH 知道該使用哪個金鑰。 config 檔案範例： Host github.com HostName github.com User git IdentityFile ~/.ssh/id_ed25519_pro 解釋： Host: 指定一個別名，方便你快速連接。 HostName: 指定實際的伺服器地址。 User: 指定登入的使用者名稱。 IdentityFile: 指定要使用的私鑰檔案路徑。 修改步驟： 開啟 .ssh/config 檔案： 使用你喜歡的文字編輯器。 新增或修改 Host 區塊： 如果已經有對應的 Host 區塊，直接修改 IdentityFile 的值。 如果沒有，新增一個 Host 區塊，並填寫相關資訊。 儲存檔案： 務必以純文字格式儲存，不要加入任何格式設定。 修改後的範例： ...
